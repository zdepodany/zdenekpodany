## Commands

```bash
pnpm build   # Runs scripts/build.js -> generates the static site into dist/
pnpm dev     # Build once, then serve dist/ locally (npx serve)
```

No test suite exists.

## Architecture

**Plain HTML/CSS/JS static site** — personal portfolio and web design agency site for Zdeněk Podaný, targeting Czech small businesses in the Znojmo region. No framework: source pages live under `src/pages/`, a small Node build script assembles them into `dist/`, which is what gets deployed.

- **Source**: `src/pages/**/*.html` (page bodies with `<!--include:NAME-->` markers), `src/partials/*.html` (shared header/footer/sections), `src/css/style.css`, `src/js/*.js`
- **Output**: `dist/` (generated by `pnpm build`, gitignored, do not edit directly)
- **Build script**: `scripts/build.js` — resolves `<!--include:partial-name-->` markers against `src/partials/`, generates blog pages from `content/blog/*.md`, then copies `src/css`, `src/js`, and `public/` into `dist/`
- **API**: `api/*.js` — standalone Vercel serverless functions (Node runtime, not tied to any framework)
- **Package manager**: pnpm (used only for the build tooling, not shipped to the browser)

### Key files & folders

| Path | Role |
|---|---|
| `src/pages/index.html` | Homepage — all main sections inline |
| `src/pages/tvorba-webu-znojmo/index.html`, `cenik/index.html`, legal pages, `404.html` | Other static pages |
| `src/pages/blog/index.html` | Blog listing template (`<!--BLOG_POSTS-->` placeholder) |
| `src/pages/blog/post.html` | Per-post template (`{{TITLE}}`, `{{DESCRIPTION}}`, `<!--BLOG_CONTENT-->`, etc.) |
| `src/partials/` | Shared header, footer (+ blog variant), cookie consent, scripts, and reusable sections (pricing, FAQ, testimonials, contact form) |
| `src/css/style.css` | Single stylesheet with CSS custom properties (former `globals.css`, Tailwind directives replaced by a small manual reset) |
| `src/js/` | Vanilla JS modules: `header.js` (nav/mobile menu/scroll progress), `scroll-reveal.js`, `cookie-consent.js`, `carousel.js`, `faq.js`, `metrics.js`, `contact-form.js`, `pricing-table.js` |
| `scripts/build.js` | Node build script — partial includes, blog generation, static asset copy |
| `content/blog/*.md` | Blog posts (gray-matter front matter + Markdown, converted at build time via `remark`) |
| `api/*.js` | Vercel serverless functions: `contact.js` (Resend email), `auth.js` + `callback.js` (GitHub OAuth for the Decap CMS admin) |
| `public/` | Static assets copied as-is into `dist/` (images, favicon, `admin/` Decap CMS, robots.txt, sitemap.xml) |
| `vercel.json` | `outputDirectory: dist`, `cleanUrls: true` |

### Adding a page

Create `src/pages/<slug>/index.html` as a full HTML document, include `<!--include:head-common-->` in `<head>` plus page-specific `<title>`/meta, and `<!--include:header-->` / `<!--include:footer-->` / `<!--include:cookie-consent-->` / `<!--include:scripts-->` in the body. Run `pnpm build` to regenerate `dist/`.

### Adding a blog post

Drop a new Markdown file into `content/blog/` with the same front matter shape as existing posts (`title`, `description`, `date`, `image`, `tags`). `pnpm build` picks it up automatically — no code changes needed.

### Analytics & consent

- Google Analytics 4 (`G-HVYTTEV5WY`) — loaded by `src/js/cookie-consent.js` only after the user accepts
- Vercel Analytics + Speed Insights — plain `<script>` tags pointing at `/_vercel/insights/script.js` and `/_vercel/speed-insights/script.js` (works automatically on Vercel, no npm package needed for a static site)
- Microsoft Clarity (`wawvgt8jxv`) — unconditional inline script in `src/partials/scripts.html`

### CSS conventions

- CSS custom properties defined at `:root` for colors (`--primary: #006DEC`), spacing, shadows, transitions
- Single file — add new rules at the relevant section rather than appending to the end
- No Tailwind — a small manual reset at the top of `style.css` replaces Tailwind Preflight

### Content language

All user-facing content is in Czech (`cs-CZ`). Keep this consistent when editing copy or adding new pages.

### Notes on the Next.js → vanilla migration

- Migrated from Next.js 15 (App Router, React, Framer Motion, Tailwind) to plain HTML/CSS/JS in 2026-07.
- `BorderGlow` (canvas-based animated border on pricing cards) was dropped rather than ported — design is expected to change soon anyway.
- `OmneSection`, `ProcWebSection`, and `VKostceSection` previously used Framer Motion `useInView` entrance animations; they now render statically (no scroll-triggered animation) since Framer Motion was removed.
